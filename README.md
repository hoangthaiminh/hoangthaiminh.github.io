# TK6-Sodolop Web Interface

Repository for the TK6-Sodolop web interface source code.

## Purpose

This repository is used to **store, maintain, and version the source code of the TK6-Sodolop web interface**.

It contains the files required for the website's frontend, including HTML, CSS, JavaScript, and related web assets.

This repository is intended primarily for source-code storage, version control, maintenance, and deployment of the web interface.

**Technology used:**

- `Font Awesome 7` (Web Fonts)
- `Howler` (Sound Effects)
- `Gsap + Moveable.js` (Animations)
