# TK6-Sodolop Web Interface

*Repository for the TK6-Sodolop web interface source code.*

## Purpose

This repository is used to **store, maintain, and version the source code of the TK6-Sodolop web interface**.

It contains the files required for the website's frontend, including HTML, CSS, JavaScript, and related web assets.

This repository is intended primarily for source-code storage, version control, maintenance, and deployment of the web interface.

<summary><h2>Additional Project Information</h2></summary>

### **Display languages:**

|Percent|Language|Code|
|-|-|-|
|$\approx 98.7\%$|__Vietnamese__|[`vi-VN`](https://en.wikipedia.org/wiki/Vietnamese_language)|
|$\approx 1.3\%$|__English__|[`en-US`](https://en.wikipedia.org/wiki/American_English)|


### **Programming languages:**

- **HTML** & **CSS** for building a responsive and clean user interface.
- **JavaScript** (Vanilla) for:
  - Managing application logic and local user data operations.
  - Handling asynchronous network requests (`POST`) to **MockAPI** for remote data persistence and tracking user visits.


### **Frameworks:**

- **No framework used.**   
(Developed from scratch using vanilla HTML5, CSS3, and JavaScript, alongside third-party libraries)


### **Third-party CSS & JavaScript libraries:**

- __`Font Awesome 7`__ (Web Fonts)
- __`Howler`__ (Sound Effects)
- __`GSAP + Moveable.js`__ (Animations)


### **Artificial Intelligence Assistance:**

- [**ChatGPT**](https://chatgpt.com) for debugging and resolving library integration issues.
- [**Claude**](https://claude.ai) for code optimization and minification to ensure smooth browser execution.

### **Development Philosophy:**

All core architecture, concepts, and features were independently conceived and built from scratch. AI tools were strictly limited to assisting with interface refinements, debugging, and performance optimization, with every suggestion manually reviewed and integrated.
